地图属性

工具

怎么用

1. 定好地图大小/格子，用「地面」「墙/障碍」画地形——障碍可以在左边选样式（墙体/树/石头/栅栏/水晶，碰撞都一样）；大块区域用「填充(油漆桶)」点一下铺满连通区域（可切换填地面还是填障碍）。
2. 「刷怪区」拖一个框 → 在右边勾选这区能出的怪、上限、品质。
3. 「固定怪」「传送门」点一下就摆一个；出生点必须自己摆（点「出生点」工具再点画布），不摆的话玩家从地图正中心出生。
4. 摆错了用「橡皮」点一下：点到传送门/固定怪就删掉它，没点中才擦地形格子（也可以选中后按 Del）。
5. 「选区」工具：框选拖一个矩形；划线随手画一个封闭图形、图形内部整片选中。选好后去右边「选区操作」，调好区域等级和要出的怪，点「✔ 确认」才会生效（确认前会提示"将新建/更新区域#几"）；也可以整片删掉地面/墙体/传送门/所有东西。
6. 点「导出 JSON」保存文件，发给我 → 我放进游戏；
   或者你自己打开游戏 → 开发者 → 自定义地图 → 粘贴 JSON → 导入地图。
滚轮缩放，右键拖动平移，Del 删除选中的东西。

刷怪区设置(新建/选中的)

选区操作

左边选「选区」工具：框选=拖一个矩形；划线=随手画一个封闭图形， 图形内部会被整片选中。
区域重叠时按高等级覆盖低等级：高等级区域里不会被低等级区域盖掉，低等级也盖不动高等级。
可生成的怪 = 上面「刷怪区设置」里勾的那些；上限也用上面那个。
